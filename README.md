# image-captioning-system
Bilingual Image Captioning System that generates Arabic and English captions for images using CLIP embeddings and the mT5 transformer model, with LoRA fine-tuning for efficient training.
# AI Image Captioning System (Arabic & English)

This project presents a bilingual image captioning system capable of generating descriptive captions for images in both Arabic and English. The model combines vision and language models to understand image content and produce meaningful textual descriptions.

## Overview
The system uses CLIP Vision Transformer embeddings to extract visual features from images and feeds them into an mT5 language model to generate captions. LoRA (Low-Rank Adaptation) is applied to efficiently fine-tune the language model.

The project focuses on improving caption generation quality while maintaining efficient training and inference.

## Technologies Used
- Python
- PyTorch
- Transformers
- CLIP Vision Transformer
- mT5 Language Model
- LoRA Fine-tuning

## Features
- Generates captions for images in Arabic and English
- Uses transformer-based architecture
- Efficient training with LoRA
- Image and text dataset preprocessing
- Model evaluation and performance optimization

## Workflow
1. Image preprocessing
2. Feature extraction using CLIP
3. Caption generation using mT5
4. Model fine-tuning using LoRA
5. Evaluation and performance improvement

## Applications
- Image search systems
- Assistive technologies for visually impaired users
- Content generation for media platforms
- Multilingual AI systems
